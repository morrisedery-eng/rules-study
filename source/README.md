# Rules Study (Android)

A 15-day, one-hour-a-day study app for Florida DCF's *Child Care Facility Rules and Regulations* course, in English and Hebrew.

Everything runs on the phone. The app has **no internet permission**, makes no API calls, and keeps your progress on the device.

## What's inside
- 15 daily lessons (60 minutes each) with a session timer, covering all six RNRF course modules
- A 30-question practice exam drawn from all days
- Flashcards and quizzes with explanations
- Study helper: speak or type a question in English or Hebrew; it finds the matching rule and answers with an explanation, an example and a memory tip, and can quiz you, summarize the day and read lessons aloud
- Microphone and reading aloud use Android's built-in speech services

## Build the APK

### Option A: GitHub (no software to install)
1. Create a new repository on GitHub and upload all files in this folder (keep the `.github` folder).
2. GitHub builds the app automatically (Actions tab, about 5 minutes).
3. On your phone, open the repository's **Releases → Rules Study app** page and tap `RulesStudy.apk`.

### Option B: Android Studio
Open this folder in Android Studio and choose **Build → Build APK(s)**.

## Install on your phone
1. Open the downloaded `RulesStudy.apk`.
2. If asked, allow your browser or Files app to **install unknown apps**.
3. Tap **Install**, then open **Rules Study**.
4. The first time you tap the microphone, choose **Allow**.

## Voice without internet (do once, on Wi-Fi)
- Voice typing: Settings → System → Languages & input → On-screen keyboard → Gboard → Voice typing → Offline speech recognition → download English (US) and Hebrew.
- Reading aloud: Settings → Accessibility → Text-to-speech output → Speech Services by Google → Install voice data → Hebrew.

Menu names vary slightly between phone brands.

## Source material
DCF Child Care Facility Handbook (December 2025), the RNRF participant guide, Florida Statutes 402.26–402.319 and rule 65C-22 F.A.C. (amended September 2026). If your course materials show a different number, follow your course.
